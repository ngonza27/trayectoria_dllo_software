# Fases y Cronograma del Proyecto — RFP-001: Restaurant Reservation System

**Reference:** RFP-001 · [SOW.md](../SOW.md) · [mvp_scope.md](./mvp_scope.md)

## 3. Fases y Cronograma del Proyecto

| Phase | Objective | Deliverables | Estimated Duration | Dependencies |
|---|---|---|---|---|
| Phase 1: Discovery & Scoping | Understand the reservation workflow, users, and business rules. | Scoping questionnaire, MVP scope, risks, assumptions, refined backlog. | 1 week | Stakeholder availability |
| Phase 2: Requirements & UX Design | Define user stories, reservation rules, and interface flows. | User stories, acceptance criteria, wireframes, data model draft. | 1 week | Answers from discovery questions |
| Phase 3: MVP Development - Core Reservations | Build the main reservation workflow. | Create, update, cancel, and view reservations. | 2 weeks | Approved MVP scope and wireframes |
| Phase 4: Availability & Calendar View | Add availability checking and shared calendar visibility. | Availability logic, branch/date/time filters, calendar/list view. | 1-2 weeks | Table capacity rules and branch schedules |
| Phase 5: Testing & Refinement | Validate booking and cancellation workflows. | Test cases, testing evidence, bug fixes, usability improvements. | 1 week | Completed MVP features |
| Phase 6: Handoff & Onboarding | Prepare staff to use the system. | Staff onboarding guide, demo, final presentation. | 1 week | Stable MVP and completed testing |
