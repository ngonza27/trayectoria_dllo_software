## MVP Definition

The MVP will be a simple web application that allows Fresh Fork staff to manage restaurant reservations for one or more branches. Staff should be able to create, update, cancel, and check reservations using a shared calendar. The system should reduce double bookings, make availability easier to check, and give managers a basic shared view of reservation activity.
